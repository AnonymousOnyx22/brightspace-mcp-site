Set up Brightspace MCP.

Open this page on your Mac or Windows laptop. Brightspace MCP works in the Claude app there.

  1. Open a terminal. You need Node.js 20 or newer.
  2. Run the command below.
  3. Sign in to your school in the window that opens, then ask your AI "What should I work on right now?"
$npx brightspace-d2l-mcp setup
