What is Brightspace MCP?

Brightspace MCP is a D2L Brightspace MCP server: it connects your Brightspace courses to AI apps like Claude, ChatGPT, Cursor and Copilot. Ask "what should I work on right now?" and get an answer that skips the work you already handed in.

See what you can ask

What MCP means

MCP stands for Model Context Protocol. It's the open standard AI apps use to connect to other software. An MCP server is the piece that does the connecting, so a Brightspace MCP server (or D2L MCP server) is what lets an AI assistant read D2L Brightspace for you.

What Brightspace MCP can do

✅ Real to-do list

Checks your actual submission for every assignment, so it only shows what's left.

📊 Grades

Grades per course, and what you need on the final to reach a target.

📝 Exams and calendar

Exam dates, labs and classes from your course calendars.

📚 Course files

Reads slides, handouts, rubrics and assignment instructions.

🔔 What's new

New announcements, newly marked work and unread discussions.

⏰ Alerts

Desktop alerts before deadlines and when new grades are posted.

How it signs in to D2L Brightspace

You sign in on your school's own Brightspace page in a normal browser window, so Microsoft, Duo, Okta and Shibboleth single sign-on all work. Your password is never seen or stored. Brightspace MCP is read-only: it can't submit, post or change anything, and it runs on your own computer.

Which AI apps it works with

Claude Desktop (one-click install), ChatGPT, Cursor, VS Code with GitHub Copilot, Windsurf, Claude Code and other apps that support MCP. Guides: Brightspace + Claude · Brightspace + ChatGPT · Brightspace MCP servers compared.

Questions

If your school uses D2L Brightspace, yes. You sign in the same way you always do.
