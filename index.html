What is Brightspace MCP?

Brightspace MCP is a D2L Brightspace MCP server. MCP (Model Context Protocol) is the standard way AI apps connect to other software. This server connects your D2L Brightspace account to Claude, ChatGPT, Cursor and Copilot, so your AI can see your courses, due dates, what you've handed in, grades and course files. It works at any school that uses D2L Brightspace. Learn how it works.

Get started

Set it up

One command, any AI app

Needs Node.js 20 or newer. Open a terminal and run this. It asks for your school, opens a sign-in window and connects Claude, Cursor and the other apps it finds.

$npx brightspace-d2l-mcp setup

Prefer a download? Pick your computer. Using Cursor, VS Code, Windsurf or another AI app? Pick your computer:

  1. Download the setup file and double-click it. If Node.js isn't installed, it opens the installer first: click through it, then run the setup file again.
  2. If Windows shows "Windows protected your PC", click More info, then Run anyway. The file only runs the setup command below.
  3. Sign in to Brightspace in the window that opens. Done.
Download setup for Windows

Prefer typing it? Open PowerShell and run:

>npx -y brightspace-d2l-mcp setup

FAQ

What is Brightspace MCP?

A D2L Brightspace MCP server: it connects Brightspace to AI apps like Claude and ChatGPT using MCP (Model Context Protocol), so they can read your due dates, submissions, grades and course files. More about Brightspace MCP.

Does it work at my school?

If your school uses D2L Brightspace, yes. Setup opens a normal browser window so any sign-in works, including Microsoft, Duo, Okta and Shibboleth.

Does it work on my phone?

Brightspace MCP runs on your Mac, Windows or Linux computer, inside your AI app. Open this page on your laptop to set it up.

Is my password saved?

No. You type your password into your school's own sign-in page in a real browser. The tool only keeps the session, on your own computer.

Can it submit work or change anything?

No. Every tool is read-only and only ever reads from Brightspace. A test in the code fails if that ever changes.

Where does my data go?

Nowhere but your own computer and AI app. It talks only to your school's Brightspace, with no server in between and no analytics. See the privacy policy.

Are the setup files safe?

Yes. The Windows file is a short text file you can open in Notepad, and the Mac installer is readable at brightspacemcp.com/install.sh. Both only install Node.js into your user folder if it's missing, then run setup.

How do I add it to Claude?

Run npx brightspace-d2l-mcp setup. It adds Brightspace to Claude Desktop and Claude Code for you. ChatGPT works through developer mode, see the ChatGPT guide.

Does it cost anything?

No. It is free and open source, with no account, no key and no subscription.

Something isn't working

Run npx -y brightspace-d2l-mcp doctor. It checks everything and tells you how to fix it. Or contact us.
