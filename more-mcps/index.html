Free student MCP servers

MCP servers let AI apps like Claude, ChatGPT and Cursor use real tools. These ones are made for students. Every one is free, open source and needs no account. The ones that touch your school accounts are read only, so they can never submit or change anything.

How to add one

Every server works the same way in any app that supports MCP. In Claude Desktop, add it to claude_desktop_config.json with command npx and the package name as the argument, then restart. In Claude Code run claude mcp add name -- npx -y package-name. Each README has the exact config. You need Node.js 20 or newer.
