Install guide

Install Brightspace MCP in Claude

About 2 minutes on Windows, Mac or Linux. It is free. You need Node.js 20 or newer and the Claude desktop app.

  1. Open a terminal. On Windows open PowerShell. On Mac open Terminal.
  2. Run setup.
    $npx brightspace-d2l-mcp setup
  3. Type your school. Paste any Brightspace link from your browser so it knows your school.
  4. Sign in. A normal browser window opens. Sign in the way you always do. Your password is never stored.
  5. Restart Claude. Setup adds Brightspace to Claude Desktop and Claude Code. Start a new chat and ask "What should I work on right now?"

Something look different?

Node.js isn't installed

Install it from nodejs.org, close the terminal, open a new one and run the command again.

The sign-in window didn't open

Run npx brightspace-d2l-mcp doctor. It checks everything and says how to fix it. If Chrome or Edge isn't installed, the first time takes a minute longer while it gets a small browser for signing in.

Claude doesn't show Brightspace

Quit Claude fully and reopen it. If it still isn't there, run npx brightspace-d2l-mcp status.
