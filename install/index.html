Install guide

Install Brightspace MCP in Claude

About 2 minutes on a Windows or Mac laptop. You need the Claude desktop app and the file from the Add to Claude button on your key page.

  1. Download your file. On your key page, click Add to Claude. A file called Brightspace MCP Pro.mcpb lands in your Downloads folder. Your key and school are already inside it.
  2. Open Claude's Settings. In the Claude app, press Ctrl , on Windows or ⌘ , on Mac. You can also click your name at the bottom left and choose Settings.
  3. Go to Extensions. In the left menu, scroll to This computer and click Extensions.
  4. Install the file. On the Extensions page, click Advanced settings, then Install Extension…, and choose Brightspace MCP Pro.mcpb from Downloads. Claude shows an install screen with your key and school filled in. Click Install.
  5. Ask Claude. Start a new chat and type "What should I work on right now?" The first time, a browser window opens: sign in to Brightspace the way you always do. That's it.

Something look different?

Windows asks "Select an app to open this .mcpb file"

Close that box. Windows just doesn't know the file type yet. Install it from inside Claude instead, using steps 2 to 4 above.

I can't find Extensions in Settings

Update Claude first: in the app, open the menu and choose Check for updates, or reinstall from claude.ai/download. In some versions it's under Connectors, then Desktop extensions.

Claude says the extension isn't verified

That's expected for extensions installed from a file. Click to continue and install.

The key or school box is empty

Paste your key from your key page, and your school's Brightspace address from your browser's address bar when you're on Brightspace (for example yourschool.brightspace.com).

Claude says it can't find my school

In Claude, open Settings, Extensions, Brightspace MCP Pro, fix the Brightspace address, then quit and reopen Claude.

The sign-in window didn't open

Ask Claude again. If Chrome or Edge isn't installed, the first time takes a minute longer while it downloads a small browser for signing in.
