How to use D2L Brightspace with ChatGPT

ChatGPT can read your Brightspace courses through Brightspace MCP running on your own computer. ChatGPT connects to MCP servers over the internet, so this needs HTTP mode and a tunnel. It takes about five minutes.

Steps

  1. Start your free trial. Get your key at brightspacemcp.com/pro. The first 7 days are free.
  2. Run setup. Run npx -y https://brightspacemcp.com/pro/brightspace-mcp-pro.tgz setup, paste your key and sign in to your school's Brightspace.
  3. Start HTTP mode. Run npx -y https://brightspacemcp.com/pro/brightspace-mcp-pro.tgz serve --http. It prints a private URL with a token.
  4. Open a tunnel. Make the local URL reachable, for example with cloudflared tunnel --url http://127.0.0.1:8787.
  5. Add the connector. In ChatGPT open Settings, Apps and Connectors, Advanced, turn on Developer mode and create a connector with the tunnel URL and no authentication.
  6. Ask ChatGPT. Start a chat with the connector on and ask what is due this week.
npx -y https://brightspacemcp.com/pro/brightspace-mcp-pro.tgz setup
npx -y https://brightspacemcp.com/pro/brightspace-mcp-pro.tgz serve --http
cloudflared tunnel --url http://127.0.0.1:8787

Keep the URL private. Anyone with it can read your Brightspace while the server and tunnel run. Stop both with Ctrl+C when you're done.
